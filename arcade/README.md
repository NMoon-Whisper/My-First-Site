# Pixel Vault Arcade

An isolated arcade section; the existing site homepage remains unchanged.

## Legal catalog
This initial section includes only an original browser canvas game. No third-party arcade ROMs, BIOS files, full sets, or third-party box art are bundled. Do not add a title until its redistribution rights are documented and verified.

## Local files
The local file player is an optional integration and does not make any ROM legal or compatible. User-selected files must stay in the browser and must never be sent to a server. Emulator support, save states, and archive handling depend on the exact core/runtime and must be tested before production claims.

## Production test status
This is not a device-lab test report. Browser compatibility, emulator boot, save states, input latency, and 60 FPS have not been certified. Verify these with a legally redistributable test game before release.
